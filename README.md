# Vestige: Heritage Walking Tours

Front-end project for a walking-tour company: a Blazor Web App (.NET 8, Interactive Server) styled with Tailwind CSS 3. Three pages: Home, Our Story and Reviews.

## Requirements
- .NET 8 SDK
- Node.js and npm (only for building the Tailwind CSS)

## Run
```powershell
npm install
npm run css:build
dotnet run
```
Then open the URL printed in the terminal (see `Properties/launchSettings.json`).

While editing markup or styles, keep Tailwind running in a second terminal:
```powershell
npm run css:watch
```
`dotnet run` and `dotnet watch` do not rebuild the CSS. If new classes do not show up, `css:watch` is not running or the build failed.

## Structure
PascalCase for C#/Razor files and folders, lowercase for `wwwroot` assets.
```
Components/
  Layout/   MainLayout.razor (header, mobile menu, footer)
  Pages/    Home, OurStory, Reviews
  Shared/   PageHeader, Photo, StarRating
Models/     Review.cs
Services/   ReviewService.cs (in-memory store)
Styles/     app.css (Tailwind input)
wwwroot/
  css/      app.css (generated by Tailwind, committed)
  js/       site.js (header on scroll, scroll reveal)
  images/
```

## Tailwind
- Input: `Styles/app.css`. Config: `tailwind.config.js`. Output: `wwwroot/css/app.css` (generated, do not edit by hand).
- Custom theme values: `font-display`, `font-body`, `tracking-wider2`, `ease-lux`.
- Tailwind 3 removes custom rules inside `@layer` when their classes never appear in a `.razor` file. Rules for classes added only by `site.js` (such as `[data-reveal].is-visible`) must stay outside `@layer`.

## Images
Put photos in `wwwroot/images`. The pages use:

`hero.jpg`, `story.jpg`, `story-2.jpg`, `cta.jpg`, `moment-1.jpg`, `moment-2.jpg`, `tour-old-town.jpg`, `tour-landmarks.jpg`, `tour-food.jpg`

A missing file shows a terracotta gradient instead, so the page still works without them.

## Sample content
Reviews are kept in memory by `ReviewService` and reset when the app restarts. The two seed reviews, tour descriptions and photo captions are placeholders: replace them before submitting.
